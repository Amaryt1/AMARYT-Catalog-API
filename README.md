# AMARYT Catalog API

Static, paginated app catalog generated by GitHub Actions and published with GitHub Pages. This repository is independent of Feather and Mstoda.

## Setup

1. In Settings → Pages, select **GitHub Actions** as the deployment source.
2. Run **Actions → Build and publish catalog → Run workflow**.
3. Once published, fetch `https://amaryt1.github.io/AMARYT-Catalog-API/api/manifest.json` and `api/pages/000000.json`.

The client should fetch the first page (50 items), paginate on demand, and cache responses locally. It must not download the entire catalog at startup. GitHub Pages is a static API, not a server-side query engine; global search needs a separate index or service. Source failures preserve the previous published output by aborting the build.
